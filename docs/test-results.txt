== 4. Not checked ==
- No real FortiGate backup or log file has been processed. Field coverage relies on the CLI and
  Log References and on the synthetic generator.
- Not run on Windows or macOS (only Linux, Python 3.10.20 and 3.13.18).
- The window (tkinter) was only tested on Linux under a virtual display (Xvfb). File dialogs were
  not clicked through automatically; adding files was tested by passing paths at start.
- Encrypted-backup detection is heuristic; tested only with made-up samples.
- Free-text msg wording of BGP/OSPF and interface events is not documented verbatim; tested only
  with the generator's wording (log IDs are matched first).
- FortiOS versions other than 7.4, 7.6 and 8.0 only tested for the warning path.
- The HTML report was checked visually in Chromium (light, dark, phone width) only.
